# AdZU ScheduleBud 2.0

Foundation and pure-domain implementation for a local-first AdZU schedule wallpaper generator.

```bash
npm install
npm test
npm run typecheck
npm run lint
npm run build
```

See `docs/architecture.md` and `docs/source-data-report.md`. Creation flows, the Zustand/Dexie project layer, and the first React Konva vertical slice are deliberately deferred to later phases.
